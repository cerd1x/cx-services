# AI Rules Execution

Integration AI for Human

## Rules

1. Untuk Dapat Merubah Source Code Ai Harus Memaparkan Errornya Apa?
2. Kemudian Saya Memilih Yang Harus Saya Selesaikan,
3. Lakukan Apa yang saya Perintahkan saja,
4. dan jika ada perbaikan yang lain Yang Menyakut Tentang Pilihan saya Harus Bertanya Kepada saya apakah Harus di Proses atau tidak
5. Jangan menjalankan type checking secara otomatis setiap kali saya menjalankan perintah. Hanya jalankan jika saya meminta secara eksplisit atau jika diperlukan untuk verifikasi akhir dari task yang saya minta.
6. Ketika AI akan menjalankan command, AI harus memaparkan command apa yang akan dijalankan terlebih dahulu, lalu saya yang mengkonfirmasi apakah command tersebut boleh dijalankan atau tidak.
